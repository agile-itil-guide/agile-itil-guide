# 한국어 (대한민국) 용어집

번역자들은 이 선택을 일관되게 적용합니다. 고유명(ITIL, Scrum, Kanban, DevOps, DORA, SRE, 도구와 제품 이름)은 원어 그대로 둡니다. 확립된 한국어 대응어가 없는 경우 각 주제에서 처음 나올 때 영어 용어를 괄호 안에 병기합니다. 영어판 Wikipedia 링크, 참고 문헌 제목, 스킬 파일 이름은 영어로 유지합니다. 한국어 본문은 아라비아 숫자(0–9)를 쓰고 합니다체를 사용합니다. 예시의 통화는 미국 달러, 날짜는 연-월-일, 단위는 미터법입니다. 주제 간 상호 참조는 "주제 N.N — 제목" 형식입니다.
