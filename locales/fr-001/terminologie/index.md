# Glossaire de fr-001 (Français)

Les traducteurs appliquent ces choix de façon cohérente. Les noms propres (ITIL, Scrum, Kanban, DevOps, DORA, SRE et les noms d'outils et de produits) restent tels qu'en anglais. À la première occurrence d'un terme dans chaque sujet, lorsqu'il n'existe pas de terme français établi, le terme anglais est donné entre parenthèses. Les liens Wikipédia en anglais, les titres des références et les noms de fichiers de compétences restent en anglais. Dans le texte français, on emploie la ponctuation française (espace insécable avant « : », « ; », « ? » et « ! ») et les chiffres arabes occidentaux (0–9). Monnaie des exemples : dollar américain ; dates AAAA-MM-JJ ; unités métriques. Les nombres utilisent l'espace comme séparateur de milliers. Renvois : « Sujet N.N — Titre ».
