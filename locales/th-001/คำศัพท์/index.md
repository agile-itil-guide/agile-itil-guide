# ไทย (ประเทศไทย): คำศัพท์

ผู้แปลยึดถือการตัดสินใจต่อไปนี้โดยตลอด ชื่อเฉพาะ (ITIL, Scrum, Kanban, DevOps, DORA, SRE และชื่อเครื่องมือและผลิตภัณฑ์) คงไว้ในรูปอักษรละติน ในกรณีที่ไม่มีคำไทยที่ใช้กันแพร่หลาย จะแสดงคำภาษาอังกฤษในวงเล็บเมื่อปรากฏครั้งแรกในแต่ละหัวข้อ ลิงก์ ชื่อแหล่งอ้างอิง และชื่อไฟล์ทักษะคงเป็นภาษาอังกฤษ ส่วนเนื้อหาของพรอมต์ปัญญาประดิษฐ์คงเป็นภาษาอังกฤษในบล็อก `text` พร้อมบรรทัดแสดงจุดประสงค์ภาษาไทย ("วัตถุประสงค์:") ในข้อความภาษาไทยใช้เลขอารบิก (0-9) วันที่เขียนเป็น YYYY-MM-DD จำนวนเงินระบุเป็นดอลลาร์สหรัฐ (USD) และใช้หน่วยเมตริก การอ้างอิงข้ามระหว่างหัวข้อใช้รูปแบบ "หัวข้อ N.N — ชื่อหัวข้อ"
